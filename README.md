# Scripture Vault

Read the Bible and keep study notes that link themselves.

- Nine versions, all public domain: KJV, WEB, Berean Standard (BSB), ASV, Young's Literal, Darby, Geneva 1599 (original spelling), Douay-Rheims, Bible in Basic English
- Tap a verse to write a note on it or link a name, place, or theme to its own vault page
- Every time a vault name appears, in scripture or your notes, it's highlighted and linked
- Verse references in notes (John 3:16, 1 Cor 13:4-7, Ps 23) become tap-to-open links
- Search the whole Bible; find every verse a vault name appears in
- Works offline. Notes stay on the phone (Copy backup / Restore in the ⋯ menu)

Web: https://cloudstifa1-cpu.github.io/scripture-vault/
Android app: https://github.com/cloudstifa1-cpu/scripture-vault/releases/latest/download/scripture-vault.apk

Bible text sources: KJV, BSB, ASV, YLT, Darby, Geneva 1599, Douay-Rheims and BBE from scrollmapper/bible_databases; World English Bible from TehShrike/world-english-bible.
